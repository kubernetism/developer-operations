# DevOps Course Repository

This repository is a structured learning path for a DevOps and systems engineering course. It contains beginner to intermediate topics that build a strong foundation in Linux, Git, YAML, system design, databases, and Docker.

## Course Overview

The course is organized into a progressive sequence of modules:

1. Introduction to DevOps
2. Introduction to Linux
3. Advanced Linux
4. Linux Assignment
5. Git and GitHub
6. Introduction to YAML
7. YAML and GitHub Assignment
8. System Design (Part 1)
9. System Design (Part 2)
10. System Design (Part 3)
11. Introduction to Databases
12. Introduction to Docker
13. Docker Assignment

This order is designed to move from foundational operating system skills to version control, configuration, architecture, data management, and containerization.

## Module Highlights

### 01 - Introduction to DevOps
This module introduces the DevOps philosophy, lifecycle, team collaboration, and the principles behind automation, continuous integration, continuous delivery, and deployment.

### 02 - Introduction to Linux
Focuses on Linux basics, file systems, navigation, permissions, processes, networking, users, shell usage, and troubleshooting.

### 03 - Advance Linux
Covers advanced shell commands, scripting, process control, systemd, cron jobs, networking utilities, diagnostics, and operations-focused Linux practices.

### 04 - Linux Assignment
A practical assignment to reinforce the Linux concepts learned in the earlier modules.

### 05 - Git and GitHub
Introduces source control, repositories, branching, Git workflows, pull requests, and collaboration practices used in modern DevOps workflows.

### 06 - Introduction to YAML
Explains YAML syntax, data structures, configuration usage, and how YAML is used in automation, CI/CD, Kubernetes, and infrastructure files.

### 07 - YAML and GitHub Assignment
Applies YAML and GitHub workflows in a hands-on assignment.

### 08 - 10 - System Design
Covers foundational system design concepts, architecture decisions, scalability, reliability, and trade-offs when building technical systems.

### 11 - Introduction to Databases
Focuses on database concepts, types of databases, data modeling, queries, and the role of databases in application and infrastructure design.

### 12 - Introduction to Docker
Introduces containerization, image creation, container lifecycle, Docker commands, and basic container use cases.

### 13 - Docker Assignment
A practical exercise to reinforce containerization concepts using Docker.

## Recommended Learning Path

1. Start with the DevOps and Linux modules.
2. Practice the Linux assignment before moving forward.
3. Learn Git and GitHub to understand version control workflows.
4. Study YAML and configuration management basics.
5. Move into system design and database concepts.
6. Finish with Docker and container-based deployment practices.
